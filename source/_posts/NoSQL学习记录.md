# NoSQL学习记录



##  NoSQL概述

NOSQL = Not only SQL “不仅仅是SQL”

NoSQL：重点突出解决处理**速度的响应**和**海量数据的存储问题**

大数据定义为高速、巨量、且多变的数据

使用NoSQL数据库的唯一标准：**只要传统关系型的数据库不撒长的，都能使用NoSQL数据库**

NoSQL分类：键值，文档，列簇、图、其他存储数据库
