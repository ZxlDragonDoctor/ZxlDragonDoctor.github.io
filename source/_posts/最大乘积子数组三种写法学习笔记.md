# 最大乘积子数组的三种写法：回溯、动态规划与滚动变量

「最大乘积」看起来只是在数组里找一个乘积最大的范围，但负数和零会让问题变得特别一些。本文从最初的回溯代码出发，再介绍完整动态规划和滚动变量优化，重点讲清楚每种写法解决什么问题。

本文按三种思路展开：

1. 回溯枚举任意子集：理解最初代码为什么不适用于连续子数组。
2. 动态规划数组：用 `maxF` 和 `minF` 记录每个位置的状态。
3. 滚动变量：只保留上一位置的状态，将空间降到 `O(1)`。

## 对应力扣题目

[152. 乘积最大子数组（Maximum Product Subarray）](https://leetcode.com/problems/maximum-product-subarray/)

---

## 一、先明确题目：子数组必须连续

以常见的「最大乘积子数组」问题为例，给定一个整数数组，要求找出一个**非空连续子数组**，使子数组中的元素乘积最大。

例如：

```text
输入：[2, 3, -2, 4]
答案：6
说明：连续子数组 [2, 3] 的乘积是 6。
```

“连续”是关键。对于 `[2, 3, -2, 4]`，不能跳过 `-2` 再把 `2、3、4` 组合起来，因为它们不是原数组中的连续一段。

---

## 二、写法一：回溯代码实际枚举的是任意子集

最初的回溯代码在做两件事：对每个元素尝试选或不选；并且先排序、跳过重复值和零。这个思路关注的是“选哪些元素”，并不保证所选元素在原数组中连续。

例如原数组是 `[2, 3, -2, 4]`，如果选出 `2、3、4`，回溯会把它们相乘；但这不符合最大乘积子数组的定义，因为中间跳过了 `-2`。

因此，最初的回溯代码不能解决连续子数组问题。它也有几个独立的边界问题：

- 跳过 `0` 会漏掉可能的最大答案，例如 `[0]` 的答案就是 `0`。
- 去重会把重复数字当成同一个选择，但数组里相同的数字仍是不同元素，例如 `[2, 2]` 可以同时选择两个 `2`。
- 从乘积 `1` 更新答案，相当于把空集合也当成候选；但题目要求子数组非空。例如 `[-2]` 的答案是 `-2`，不是 `1`。
- 枚举任意子集需要 `O(2^n)` 时间，数组稍长就会很慢。

### 如果题目确实允许任意选择元素

如果题意是“从数组中任意选取至少一个元素，使乘积最大”，那么选或不选的回溯可以作为暴力解法。这个问题与连续子数组不同：排序不是必须的，重复元素和零也不能随意跳过。

```java
class Solution {
    long best;

    public long maxSubsetProduct(int[] nums) {
        if (nums == null || nums.length == 0) {
            return 0;
        }

        best = Long.MIN_VALUE;
        dfs(nums, 0, 1L, false);
        return best;
    }

    private void dfs(int[] nums, int index, long product, boolean chosen) {
        if (index == nums.length) {
            if (chosen) {
                best = Math.max(best, product);
            }
            return;
        }

        // 不选当前元素
        dfs(nums, index + 1, product, chosen);

        // 选当前元素，包括重复值和 0
        dfs(nums, index + 1, product * nums[index], true);
    }
}
```

这段代码解决的是任意子集的最大乘积，时间复杂度为 `O(2^n)`，递归栈空间为 `O(n)`。使用 `long` 只能扩大数值范围，输入较大时仍可能溢出。

## 三、写法二：动态规划数组

最大乘积子数组的难点在于负数：

- 正数乘以较大的正数，可能得到更大的正数；
- 负数乘以较小的负数，可能得到更大的正数。

所以在每个位置，不能只记录“以当前位置结尾的最大乘积”，还要记录最小乘积。最小值遇到负数后，可能翻转成最大值。

定义：

- `maxF[i]`：以 `i` 结尾的连续子数组中的最大乘积。
- `minF[i]`：以 `i` 结尾的连续子数组中的最小乘积。

对于当前位置 `nums[i]`，新的子数组要么从当前位置重新开始，要么接在前一个位置的最大或最小乘积后面：

```text
maxF[i] = max(nums[i], maxF[i - 1] × nums[i], minF[i - 1] × nums[i])
minF[i] = min(nums[i], maxF[i - 1] × nums[i], minF[i - 1] × nums[i])
```

初始化时，只有第一个元素：

```text
maxF[0] = minF[0] = nums[0]
答案 = nums[0]
```

### Java 实现

```java
class Solution {
    public int maxProduct(int[] nums) {
        if (nums == null || nums.length == 0) {
            return 0;
        }

        int n = nums.length;
        int[] maxF = new int[n];
        int[] minF = new int[n];

        maxF[0] = nums[0];
        minF[0] = nums[0];
        int answer = nums[0];

        for (int i = 1; i < n; i++) {
            int value = nums[i];
            int prevMax = maxF[i - 1];
            int prevMin = minF[i - 1];

            maxF[i] = Math.max(value,
                    Math.max(prevMax * value, prevMin * value));

            minF[i] = Math.min(value,
                    Math.min(prevMax * value, prevMin * value));

            answer = Math.max(answer, maxF[i]);
        }

        return answer;
    }
}
```

答案要在每个位置累计更新：`answer = Math.max(answer, maxF[i])`。只返回最后一个位置的最大乘积是不对的，因为最大子数组可能在更早的位置结束。

时间复杂度为 `O(n)`，空间复杂度为 `O(n)`。

## 四、写法三：滚动变量优化

计算第 `i` 个位置时，只会用到第 `i - 1` 个位置的 `maxF` 和 `minF`。因此不需要保存整个数组，只保留上一轮的两个状态：

- `mx`：以当前位置结尾的最大乘积。
- `mn`：以当前位置结尾的最小乘积。

### 容易犯的错误：更新一个变量后又用它算另一个变量

下面这种写法有问题：

```java
mx = Math.max(mx * nums[i], Math.max(mn * nums[i], nums[i]));
mn = Math.min(mx * nums[i], Math.min(mn * nums[i], nums[i]));
```

第二行里的 `mx` 已经是当前位置的新值；但计算新的 `mn` 时，应该使用上一轮的旧 `mx` 和旧 `mn`。两个新状态都必须基于同一组旧状态计算。

例如 `[2, -5, -2, -2]`，如果直接覆盖 `mx`，后续计算可能把 `mn` 算成不属于任何连续子数组的乘积，进而得到错误答案。

### 正确实现：先保存上一轮状态

```java
class Solution {
    public int maxProduct(int[] nums) {
        if (nums == null || nums.length == 0) {
            return 0;
        }

        int mx = nums[0];
        int mn = nums[0];
        int answer = nums[0];

        for (int i = 1; i < nums.length; i++) {
            int value = nums[i];
            int prevMax = mx;
            int prevMin = mn;

            mx = Math.max(value,
                    Math.max(prevMax * value, prevMin * value));

            mn = Math.min(value,
                    Math.min(prevMax * value, prevMin * value));

            answer = Math.max(answer, mx);
        }

        return answer;
    }
}
```

现在 `mx` 和 `mn` 都只依赖 `prevMax`、`prevMin`，不会互相污染。时间复杂度仍是 `O(n)`，空间复杂度从 `O(n)` 降为 `O(1)`。

### 计算过程示例

对 `[2, -5, -2, -2]` 逐步计算：

| 当前值 | 以当前位置结尾的最大乘积 `mx` | 最小乘积 `mn` | 全局答案 |
|---:|---:|---:|---:|
| 2 | 2 | 2 | 2 |
| -5 | -5 | -10 | 2 |
| -2 | 20 | -2 | 20 |
| -2 | 4 | -40 | 20 |

最后答案是 `20`，对应连续子数组 `[2, -5, -2]`。

## 五、三种写法对比

| 写法 | 解决的问题 | 时间复杂度 | 额外空间 |
|---|---|---:|---:|
| 回溯选或不选 | 任意子集最大乘积，不要求连续 | `O(2^n)` | `O(n)` 递归栈 |
| DP 数组 `maxF/minF` | 最大乘积连续子数组 | `O(n)` | `O(n)` |
| 滚动变量 `mx/mn` | 最大乘积连续子数组 | `O(n)` | `O(1)` |

回溯和动态规划解决的题意并不相同：回溯枚举哪些元素被选择，动态规划则维护以当前位置结尾的连续区间。

---

## 六、总结

学习这道题时，可以按下面的顺序理解：

1. 先确认题目要求的是连续子数组，还是任意子集。
2. 如果要求连续，不能排序，也不能跳过中间元素。
3. 因为负数会翻转乘积大小，每个位置要同时记录最大值和最小值。
4. 完整 DP 数组帮助表达状态；确认只依赖上一位置后，可以压缩成滚动变量。
5. 滚动更新时，先保存上一轮的 `mx`、`mn`，再计算两个新状态。

滚动变量的核心模板是：

```java
int prevMax = mx;
int prevMin = mn;

mx = ...使用 prevMax 和 prevMin 计算...;
mn = ...使用 prevMax 和 prevMin 计算...;
```

空间优化不是简单地把数组替换成变量，还要保证每个新状态仍然读取正确的旧状态。
