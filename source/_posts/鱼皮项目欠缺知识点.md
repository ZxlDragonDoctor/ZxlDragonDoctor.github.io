##await async 的底层原理 
async/await是一种用于处理异步操作的Promise语法糖，使得编写异步代码变得更加简单和易读。通过使用async关键字声明一个函数为异步函数，并使用await关键字等待Promise的解析（完成或拒绝），以同步的方式编写异步操作的代码。async 函数:

当函数被标记为async 时，它会自动返回一个 Promise。

**在async 函数内部，可以使用 await 关键字来等待一个 Promise 的解决。如果 await 后面的表达式不是一个 Promise，它会被自动包装成一个 Promise。**

**await 等待成功（Promise 对象**

await:当遇到 await 关键字时，函数的执行会暂停，直到 await 后面的 Promise 被解决。如果 Promise 被成功解决， await 表达式的值就是 Promise 的结果;如果 Promise 被拒绝，await 会抛出一个错误。

await 只能在 async 函数内部使用

当async 函数内部执行到一个 await 表达式时，函数的执行会暂停，并将控制权返回给调用者。此时注册一个回调函数，当 await 后面的 Promise 被解决时，这个回调函数会被调用，以继续执行函数的剩余部分。

如果await 后面的 Promise 被拒绝，会抛出一个错误，这个错误会被 try/catch 块捕获，或者如果没有被捕获，会导致整个 Promise 链被拒绝。
**1 .async函数的特点**

-   async修饰的函数默认返回的是**Promise对象，**所以可以放到await关键字后面来调用
-  async修饰的函数内部return的数据需要使用 await 或者 .then() 或者.catch 来接收

 **2 .await的特点**

- await关键字必须放在async修饰的函数中才能使用
- await关键字后面是一个Promise对象，如果是一个普通值会自动转为Promise对象来执行
- await会等待其后面的Promise对象的成功执行状态，将结果值赋值给 = 号前面的变量







##**router.push({ path: '/', replace: true })**‌：

- ‌**行为**‌：这个方法会在历史记录中替换当前路由，而不是添加新的历史记录。用户不能通过浏览器的回退按钮返回到前一个路由。
- ‌**适用场景**‌：适用于不需要保留历史记录，或者希望用户不能通过回退按钮返回到前一个页面的场景。

##### 具体实现方式

在Vue中，`router.push`方法可以接收一个对象作为参数，其中可以包含`path`和`replace`属性。例如：

- `router.push({ path: '/' })` 会将新路由添加到历史记录中。
- `router.push({ path: '/', replace: true })` 会在历史记录中替换当前路由，而不是添加新的历史记录。

####注意事项


````vue
// 在 Vue 组件中
this.$router.replace('/users/1')
// 带查询参数
this.$router.replace({ path: '/search', query: { q: 'vue' } })
// 命名路由，并传递参数
this.$router.replace({ name: 'user', params: { userId: 123 } })
````
当你使用对象作为参数传递给 router.push 或 router.replace 时，请注意 params 和 query 的区别。params 是路由的一部分，必须要在路由配置中定义；而 query 是 URL 的查询参数，不是路由的一部分。
如果提供了 path，params 会被忽略。你需要使用命名路由 name 来传递 params。
router.push 和 router.replace 都返回一个 Promise，允许你等到导航完成后执行某些操作。

------

### 方法 1：使用 `style` 设置 `margin-left` 自动对齐

```html
<a-row>
  <a-col flex="200px" style="margin-left: auto;">
    向右对齐的内容
  </a-col>
</a-row>
```

- `margin-left: auto` 会将列内容推到右边。

------

### 方法 2：使用 `a-row` 的 `justify` 属性

设置父级容器（`<a-row>`）的 `justify="end"` 属性，让其子项靠右排列：

```html
<a-row justify="end">
  <a-col flex="200px">
    向右对齐的内容
  </a-col>
</a-row>
```

- `justify="end"` 会让所有列靠右对齐。

------

### 方法 3：在 `a-col` 上使用 `text-align: right`

如果需要内容文字也靠右对齐，可以设置文本的 `text-align`：

```html

  <a-col flex="200px" style="text-align: right;">
    向右对齐的内容
  </a-col>
</a-row>
```

------

### 方法 4：使用 Flex 布局的 `align` 和 `justify` 属性

结合 `a-row` 的 `justify` 和 `align` 属性：

```html

  <a-col flex="200px">
    向右对齐的内容
  </a-col>
</a-row>
```

------

### 小结

- 若仅调整单个列向右对齐，推荐使用 **方法 1**（`margin-left: auto`）。
- 如果调整整个行的内容对齐，使用 **方法 2**（`justify="end"`）。
- 需要调整文本或内容对齐时，可结合 **方法 3** 或 **方法 4**。

### 关键点解释：

## VUE组件传参

在 Vue 3 中，组合式 API（Composition API）是实现组件逻辑的一种强大方式。它允许我们将组件的逻辑拆分为可复用的函数，使得代码更加模块化和易于维护。以下将通过组合式 API 的方式，讲解组件传参的实现。

---

### **1. 组合式 API 的基本概念**
组合式 API 的核心是 `setup` 函数。在 `setup` 函数中，我们可以访问组件的 `props`、`context`，并定义响应式数据、方法等。通过组合式 API，我们可以将逻辑拆分为多个可复用的函数（称为“组合函数”）。

### **2. 父组件向子组件传参（Props）**

#### **2.1 定义子组件**
在组合式 API 中，我们通过 `defineProps` 来定义子组件的 `props`。

**子组件（ChildComponent.vue）：**
```vue
<template>
  <div>
    <p>子组件接收到的消息：{{ message }}</p>
  </div>
</template>

<script setup>
import { defineProps } from 'vue';

// 使用 defineProps 定义子组件的 props
const props = defineProps({
  message: {
    type: String,
    required: true
  }
});
</script>
```

#### **2.2 使用父组件传递的数据**
父组件通过绑定属性的方式将数据传递给子组件。

**父组件（ParentComponent.vue）：**
```vue
<template>
  <div>
    <ChildComponent :message="parentMessage" />
  </div>
</template>

<script setup>
import { ref } from 'vue';
import ChildComponent from './ChildComponent.vue';

// 定义父组件的响应式数据
const parentMessage = ref("Hello from Parent!");
</script>
```

**说明：**
1. 子组件通过 `defineProps` 定义了它需要接收的 `props`。
2. 父组件通过绑定 `:message="parentMessage"` 将数据传递给子组件。
3. 子组件可以直接使用 `props.message`。

---

### **3. 子组件向父组件传参（事件）**

#### **3.1 定义子组件的事件**
在组合式 API 中，我们通过 `defineEmits` 或 `emit` 来定义和触发事件。

**子组件（ChildComponent.vue）：**
```vue
<template>
  <button @click="handleClick">点击我</button>
</template>

<script setup>
import { defineEmits } from 'vue';

// 定义子组件可以触发的事件
const emit = defineEmits(['button-clicked']);

const handleClick = () => {
  // 触发事件，并传递数据
  emit('button-clicked', { id: 1, text: 'Button clicked!' });
};
</script>
```

#### **3.2 父组件监听事件**
父组件通过监听子组件触发的事件来接收数据。

**父组件（ParentComponent.vue）：**
```vue
<template>
  <div>
    <ChildComponent @button-clicked="handleButtonClick" />
    <p>按钮信息：{{ buttonInfo.text }}</p>
  </div>
</template>

<script setup>
import { ref } from 'vue';
import ChildComponent from './ChildComponent.vue';

const buttonInfo = ref({});

const handleButtonClick = (info) => {
  buttonInfo.value = info;
};
</script>
```

**说明：**
1. 子组件通过 `defineEmits` 定义它可以触发的事件。
2. 子组件通过 `emit` 触发事件，并传递数据。
3. 父组件通过监听 `@button-clicked` 事件接收数据，并在 `handleButtonClick` 方法中处理。

---

### **4. 使用组合函数（Composition Function）**
组合式 API 的强大之处在于可以将逻辑拆分为可复用的组合函数。以下是一个示例，展示如何将子组件的逻辑封装为组合函数。

#### **4.1 封装子组件的逻辑**
我们可以将子组件的逻辑封装为一个组合函数，例如 `useButtonEvent`。

**useButtonEvent.js：**
```javascript
import { defineEmits } from 'vue';

export function useButtonEvent() {
  const emit = defineEmits(['button-clicked']);

  const handleClick = () => {
    emit('button-clicked', { id: 1, text: 'Button clicked!' });
  };

  return {
    handleClick
  };
}
```

#### **4.2 在子组件中使用组合函数**
**子组件（ChildComponent.vue）：**
```vue
<template>
  <button @click="handleClick">点击我</button>
</template>

<script setup>
import { useButtonEvent } from './useButtonEvent';

// 使用组合函数
const { handleClick } = useButtonEvent();
</script>
```

#### **4.3 父组件不变**
父组件的实现方式与之前相同，通过监听事件接收数据。

---

### **5. 总结**
通过组合式 API，我们可以清晰地定义组件的 `props` 和事件，并将逻辑拆分为可复用的组合函数。这种方式使得代码更加模块化，便于维护和复用。

####  **使用 `defineProps`**

```typescript
const props = defineProps<Props>();
```

- `defineProps` 是 Vue 3 组合式 API 提供的一个宏（在 `<script setup>` 中使用时，它会被编译器处理）。
- 它的作用是根据提供的接口或类型定义，声明组件的 `props`。
- 在运行时，`props` 是一个响应式对象，你可以通过 `props.xxx` 的方式访问父组件传递的值。

###  **什么是回调函数？**

**回调函数**是一个作为参数传递给另一个函数的函数，并在该函数内部被调用。它允许你在某个操作完成时执行特定的逻辑。

简单来说，回调函数满足以下特点：

1. <span style="color: red">**作为参数传递**：回调函数通常作为参数传递给另一个函数。</span>
2. **在某个时间点被调用**：回调函数会在某个特定的操作完成时被调用，比如异步操作完成后、事件触发时等。
3. **延迟执行**：回调函数的执行通常不是立即的，而是延迟到某个条件满足时。









##  @EqualsAndHasashCode

`@EqualsAndHashCode(callSuper = true)` 是一个注解，通常用于 Java 编程中，特别是在使用 Lombok 库时。Lombok 是一个流行的 Java 库，它通过注解的方式简化了 Java 的代码编写，减少了样板代码的生成。下面是对这个注解的详细解释：

### 1. **@EqualsAndHashCode**
这个注解的作用是自动生成 `equals()` 和 `hashCode()` 方法。这两个方法在 Java 中非常重要，尤其是在对象需要被存储到集合（如 `HashSet`、`HashMap`）或者需要比较对象是否相等时。

- **`equals()` 方法**：用于判断两个对象是否相等。
- **`hashCode()` 方法**：用于生成对象的哈希码，通常用于哈希表相关操作。

### 2. **`callSuper = true`**
这个参数的作用是指示 Lombok 在生成 `equals()` 和 `hashCode()` 方法时，是否调用父类的 `equals()` 和 `hashCode()` 方法。

- **`callSuper = true`**：表示在生成的方法中会调用父类的 `equals()` 和 `hashCode()` 方法。这通常用于继承场景，当子类需要继承父类的某些字段时，确保父类的字段也被考虑在内。
- **`callSuper = false`**（默认值）：表示不调用父类的 `equals()` 和 `hashCode()` 方法，只考虑当前类的字段。

### 3. **使用场景**
假设你有一个父类 `Parent` 和一个子类 `Child`，并且子类需要继承父类的字段，那么在子类上使用 `@EqualsAndHashCode(callSuper = true)` 是非常有用的。

#### 示例代码：
```java
import lombok.EqualsAndHashCode;

@EqualsAndHashCode(callSuper = true)
public class Child extends Parent {
    private String childField;
}
```

在这个例子中，Lombok 会生成 `equals()` 和 `hashCode()` 方法，这些方法会考虑父类 `Parent` 的字段以及子类 `Child` 的字段。

### 4. **注意事项**
- 如果父类没有使用 Lombok 的 `@EqualsAndHashCode` 注解，那么在子类中使用 `callSuper = true` 时，父类的 `equals()` 和 `hashCode()` 方法需要手动实现。
- 如果父类是 `java.lang.Object`（默认父类），那么 `callSuper = true` 和 `callSuper = false` 的效果是一样的，因为 `Object` 类的 `equals()` 和 `hashCode()` 方法是默认实现。







## acs-token

`acs-token` 是一种用于验证和授权的令牌，通常用于 HTTP 请求头中，以确保请求的合法性和安全性。它类似于其他常见的认证令牌（如 `access-token` 或 `auth-token`），用于标识请求的来源和权限。

### `acs-token` 的应用场景和作用
1. **身份验证**：`acs-token` 通常由服务器生成并下发给客户端，客户端在后续请求中携带该令牌，服务器通过验证令牌的有效性来确认请求是否合法。
2. **防止恶意请求**：通过在请求头中携带 `acs-token`，可以有效防止未经授权的请求，增强接口的安全性。
3. **动态生成与验证**：在某些场景下，`acs-token` 是通过特定的算法动态生成的，例如结合请求的 URL、时间戳或其他参数进行加密生成。
4. **防止重放攻击**：令牌通常具有时效性，过期后需要重新获取，从而防止恶意用户通过重放攻击的方式重复使用旧令牌。







## 冒泡(事件传播)

`e.stopPropagation()` 是一个常用于JavaScript和TypeScript中的事件处理方法，它的作用是阻止事件继续沿着DOM树传播。在Web开发中，事件传播是指当一个事件（如点击、鼠标移动等）在DOM元素上触发时，该事件会从触发它的元素开始，按照特定的顺序传播到其他元素（通常是父元素）。

事件传播主要分为三个阶段：

1. **捕获阶段（Capturing Phase）**：事件从根节点（document）开始，向目标节点（事件触发的元素）传播。
2. **目标阶段（Target Phase）**：事件到达目标节点，即事件触发的元素。
3. **冒泡阶段（Bubbling Phase）**：事件从目标节点开始，向根节点传播。

`e.stopPropagation()` 方法通常在事件处理函数中使用，用于在事件的冒泡阶段或捕获阶段阻止事件进一步传播。这对于防止事件冒泡到父元素或捕获阶段的事件处理函数非常有用，尤其是在需要精确控制事件处理行为的情况下。

例如，考虑一个嵌套的列表结构，其中每个列表项都有一个点击事件处理器。如果希望点击列表项时只触发该项的事件处理器，而不希望触发其父列表的事件处理器，可以在列表项的事件处理器中调用 `e.stopPropagation()`。

```javascript
document.getElementById('myList').addEventListener('click', function(e) {
    // 阻止事件冒泡
    e.stopPropagation();
    // 处理点击事件
    console.log('List clicked');
});

document.getElementById('myItem').addEventListener('click', function(e) {
    // 处理点击事件
    console.log('Item clicked');
});
```

在这个例子中，如果点击 `#myItem`，将只执行 `#myItem` 的事件处理器，而不会触发 `#myList` 的事件处理器，因为 `#myItem` 的事件处理器调用了 `e.stopPropagation()`。
