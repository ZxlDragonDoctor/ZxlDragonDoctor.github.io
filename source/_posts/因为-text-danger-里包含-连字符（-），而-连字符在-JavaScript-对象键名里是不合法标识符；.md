因为 `text-danger` 里包含 **连字符（-）**，而 **连字符在 JavaScript 对象键名里是不合法标识符**；  
不加引号会被解析成 **“减号表达式”**，直接报错。

------------------------------------------------
一、演示区别

| 写法                  | 是否合法 | 结果                                             |
| --------------------- | -------- | ------------------------------------------------ |
| `text-danger: true`   | ❌        | 报错：Uncaught SyntaxError: Unexpected token '-' |
| `'text-danger': true` | ✅        | 正确，键名就是字符串 `"text-danger"`             |
| `textDanger: true`    | ✅        | 合法标识符，可省略引号                           |

------------------------------------------------
二、对象字面量规则速记

- **纯字母、数字、下划线、\( 开头且不含关键字** → 可省略引号  
- **一旦含 `-`、空格、数字开头、关键字** → 必须加引号（单双引均可）

------------------------------------------------
三、在 Vue 模板里更常见的等价写法

```html
<div :class="{ 'text-danger': true, active: true }"></div>
```

同样，**`text-danger` 必须加引号**，`active` 可以不加。

------------------------------------------------
一句话：  
**引号不是 Vue 的要求，是 JavaScript 语法的要求**——键名里出现 **连字符** 就得当字符串写。
