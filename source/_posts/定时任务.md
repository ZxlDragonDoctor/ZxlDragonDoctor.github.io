# 定时任务

## 定时任务，需要专门写一个方法，启动？

------

## ✅ 是否需要“专门写一个方法来启动定时任务”？

### 答案是：**视你使用的方式而定**，分两种情况：

------

### ✅ 方式一：使用 Spring 的 `@Scheduled` 注解（最简单）

#### ✅ 不需要专门启动，Spring 会自动识别执行

你只要在方法上加 `@Scheduled`，Spring Boot 会自动帮你定时运行，不需要手动启动：

```java
@Component
public class EmailTask {

    @Scheduled(cron = "0 0 8 ? * SAT")  // 每周六早上8点执行
    public void sendWeeklyEmail() {
        System.out.println("每周六早上8点，发送邮件！");
    }
}
```

只要你在配置类上加了：

```java
@EnableScheduling
```

🔔 就自动生效了，不用你手动调用。

------

### ✅ 方式二：使用 Quartz（更强大，但复杂）

#### ✅ 你需要“手动启动”Scheduler，并注册 Job + Trigger

Quartz 是一个完整的调度框架，它不像 `@Scheduled` 那样自动帮你调度。你需要：

- 创建一个 `Job` 类（干具体的事）
- 创建一个 `Trigger`（什么时候干）
- 创建并启动 `Scheduler`

🌟 所以这里你就**确实需要写一个 `startScheduler()` 方法**，比如：

```java
public void startScheduler() throws SchedulerException {
    Scheduler scheduler = StdSchedulerFactory.getDefaultScheduler();

    JobDetail job = JobBuilder.newJob(EmailJob.class)
            .withIdentity("emailJob")
            .build();

    Trigger trigger = TriggerBuilder.newTrigger()
            .withIdentity("emailTrigger")
            .withSchedule(CronScheduleBuilder.cronSchedule("0 0 8 ? * SAT"))
            .build();

    scheduler.scheduleJob(job, trigger);
    scheduler.start(); // ✅ 你必须手动调用
}
```

然后你可以在 `CommandLineRunner` 中调用这个方法启动它：

```java
@Bean
public CommandLineRunner run(WeeklyEmailScheduler scheduler) {
    return args -> scheduler.startScheduler();
}
```

------

## ✨ 总结一句话

| 方式         | 是否需要写启动方法   | 自动启动支持 | 用途                           |
| ------------ | -------------------- | ------------ | ------------------------------ |
| `@Scheduled` | ❌ 不需要             | ✅ 自动调度   | 简单定时任务，轻量、够用       |
| Quartz       | ✅ 需要自己写启动逻辑 | ❌ 需手动调用 | 强大、灵活、支持动态添加任务等 |

------

如果你不打算搞太复杂的调度管理，直接用 `@Scheduled` 就很舒服。如果你需要动态增删任务、分布式调度、持久化任务，那就建议用 Quartz。
