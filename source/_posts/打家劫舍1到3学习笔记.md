# 打家劫舍 I、II、III：从线性 DP 到树形 DP

打家劫舍系列的共同限制是：**不能同时选择相邻的房屋**。每道题的结构不同，状态定义也随之变化：

1. **I：**房屋排成一条直线，用一维动态规划解决。
2. **II：**房屋首尾相邻形成一个环，把问题拆成两个线性范围。
3. **III：**房屋组成二叉树，对每个节点分别计算“偷”和“不偷”两种状态。

## 对应力扣题目

- [198. 打家劫舍（House Robber）](https://leetcode.cn/problems/house-robber/)
- [213. 打家劫舍 II（House Robber II）](https://leetcode.cn/problems/house-robber-ii/)
- [337. 打家劫舍 III（House Robber III）](https://leetcode.cn/problems/house-robber-iii/)

---

## 一、共同思路：对每间房作“偷或不偷”的选择

处理当前房屋时有两种选择：

- **不偷当前房屋：**答案沿用前面房屋能得到的最大金额。
- **偷当前房屋：**不能偷相邻房屋，所以金额要加上“上上间房屋之前”的最优结果。

线性排列下的基本递推关系是：

```text
dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
```

三道题的区别在于房屋之间的相邻关系：I 是直线，II 多了首尾相邻，III 则需要根据树上的父子关系判断能否同时选择。

---

## 二、打家劫舍 I：房屋排成直线

### 题目特点

房屋沿一条街排列，不能偷相邻的两间。要求获得的金额最大。[题目页面](https://leetcode.com/problems/house-robber/)

### 状态定义与递推

定义 `dp[i]` 为只考虑下标 `0` 到 `i` 的房屋时，能偷到的最大金额。来到第 `i` 间房时：

- 不偷：金额是 `dp[i - 1]`。
- 偷：金额是 `dp[i - 2] + nums[i]`。

因此：

```text
dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
```

边界可以理解为：房屋范围为空时金额为 `0`；只有一间房时，最多偷这一间。

### 示例

```text
nums = [2, 7, 9, 3, 1]
```

依次处理房屋，最优金额为：

```text
2, 7, 11, 11, 12
```

最后的 `12` 可以由第 1、3、5 间房组成，即 `2 + 9 + 1`。

### 滚动变量实现

递推时只需要前两个状态，不必保存整张 `dp` 数组：

```java
class Solution {
    public int rob(int[] nums) {
        int prevTwo = 0; // 处理当前房之前的上上个状态
        int prevOne = 0; // 处理当前房之前的上一个状态

        for (int money : nums) {
            int current = Math.max(prevOne, prevTwo + money);
            prevTwo = prevOne;
            prevOne = current;
        }

        return prevOne;
    }
}
```

`prevTwo` 和 `prevOne` 必须先用于计算 `current`，再一起向前滚动。若提前覆盖旧值，后续递推就会用错状态。

- 时间复杂度：`O(n)`。
- 额外空间复杂度：`O(1)`。

## 三、打家劫舍 II：房屋首尾相邻

### 新增的限制

房屋围成一个圆，第一间和最后一间也相邻。因此不能同时偷第一间和最后一间。[题目页面](https://leetcode.com/problems/house-robber-ii/)

### 拆成两个线性问题

任何合法方案都不可能同时包含第一间和最后一间，所以它一定属于以下两种情况之一：

1. 不偷最后一间：只考虑 `[0, n - 2]`。
2. 不偷第一间：只考虑 `[1, n - 1]`。

分别用打家劫舍 I 的线性算法计算，再取较大值：

```text
答案 = max(rob(0, n - 2), rob(1, n - 1))
```

如果只有一间房，第一间和最后一间其实是同一间，直接返回 `nums[0]`。

### Java 实现

```java
class Solution {
    public int rob(int[] nums) {
        int n = nums.length;
        if (n == 1) {
            return nums[0];
        }

        return Math.max(
                robRange(nums, 0, n - 2),
                robRange(nums, 1, n - 1)
        );
    }

    // 在线性闭区间 [start, end] 上解决打家劫舍 I
    private int robRange(int[] nums, int start, int end) {
        int prevTwo = 0;
        int prevOne = 0;

        for (int i = start; i <= end; i++) {
            int current = Math.max(prevOne, prevTwo + nums[i]);
            prevTwo = prevOne;
            prevOne = current;
        }

        return prevOne;
    }
}
```

以 `[2, 3, 2]` 为例：

- 不考虑最后一间，范围 `[2, 3]` 的最优金额是 `3`。
- 不考虑第一间，范围 `[3, 2]` 的最优金额是 `3`。
- 取较大值，答案为 `3`。

- 时间复杂度：`O(n)`。两个范围总共只扫描线性数量的房屋。
- 额外空间复杂度：`O(1)`。

## 四、打家劫舍 III：房屋组成二叉树

### 为什么不能直接套用数组递推？

数组题里相邻关系是下标相差 `1`；树题里题目规定**父节点和子节点相邻**。如果偷了当前节点，就不能偷它的左、右孩子；但可以偷孙子节点。

因此，单独记录“以这个节点为根的最大金额”不够。父节点需要知道子节点有没有被偷，所以每个节点要保留两个状态。

### 状态定义

对每个节点 `node` 定义：

- `f(node)`：偷 `node` 时，以它为根的子树可得到的最大金额。
- `g(node)`：不偷 `node` 时，以它为根的子树可得到的最大金额。

如果偷当前节点，左右孩子都不能偷：

```text
f(node) = node.val + g(node.left) + g(node.right)
```

如果不偷当前节点，左右孩子都可以各自选择偷或不偷：

```text
g(node) = max(f(left), g(left)) + max(f(right), g(right))
```

空节点的两种状态都是 `0`。最终答案是：

```text
max(f(root), g(root))
```

### 为什么使用后序遍历？

计算父节点状态时，需要先知道左右孩子的 `f`、`g`。所以要先递归处理左右子树，再计算当前节点，也就是后序遍历：**左子树 → 右子树 → 当前节点**。

### 使用 Map 保存节点状态

可以用两张 `Map` 分别保存每个节点的两种状态：`f` 保存偷当前节点时的最大金额，`g` 保存不偷当前节点时的最大金额。后序遍历先计算左右孩子的状态，再计算并保存当前节点：

```java
f.put(node,
        g.getOrDefault(node.left, 0)
      + g.getOrDefault(node.right, 0)
      + node.val);

g.put(node,
        Math.max(f.getOrDefault(node.left, 0),
                 g.getOrDefault(node.left, 0))
      + Math.max(f.getOrDefault(node.right, 0),
                 g.getOrDefault(node.right, 0)));
```

`getOrDefault(null, 0)` 在这里让空孩子的状态按 `0` 处理。为避免 `Solution` 对象重复调用时保留旧节点，Map 版可以在每次 `rob` 开始时清空两个 Map：

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    private final Map<TreeNode, Integer> f = new HashMap<>();
    private final Map<TreeNode, Integer> g = new HashMap<>();

    public int rob(TreeNode root) {
        f.clear();
        g.clear();

        if (root == null) {
            return 0;
        }

        dfs(root);
        return Math.max(f.getOrDefault(root, 0),
                        g.getOrDefault(root, 0));
    }

    private void dfs(TreeNode node) {
        if (node == null) {
            return;
        }

        dfs(node.left);
        dfs(node.right);

        int robThis = node.val
                + g.getOrDefault(node.left, 0)
                + g.getOrDefault(node.right, 0);

        int skipThis = Math.max(
                f.getOrDefault(node.left, 0),
                g.getOrDefault(node.left, 0)
        ) + Math.max(
                f.getOrDefault(node.right, 0),
                g.getOrDefault(node.right, 0)
        );

        f.put(node, robThis);
        g.put(node, skipThis);
    }
}
```

### 更简洁的写法：DFS 返回两个状态

也可以让递归函数直接返回一个长度为 `2` 的数组：`result[0]` 表示偷当前节点，`result[1]` 表示不偷当前节点。这样不需要两个 Map：

```java
class Solution {
    public int rob(TreeNode root) {
        int[] result = dfs(root);
        return Math.max(result[0], result[1]);
    }

    // 返回 [偷当前节点的最大金额, 不偷当前节点的最大金额]
    private int[] dfs(TreeNode node) {
        if (node == null) {
            return new int[] {0, 0};
        }

        int[] left = dfs(node.left);
        int[] right = dfs(node.right);

        int robThis = node.val + left[1] + right[1];
        int skipThis = Math.max(left[0], left[1])
                     + Math.max(right[0], right[1]);

        return new int[] {robThis, skipThis};
    }
}
```

每个节点只处理一次：

- 时间复杂度：`O(n)`，`n` 为节点数。
- 递归栈空间：`O(h)`，`h` 为树高。
- 返回状态的写法不需要额外的 `O(n)` Map；Map 写法还需要为每个节点保存两份状态。

### 树形例子

```text
        3
       / \
      4   5
     / \   \
    1   3   1
```

偷根节点 `3` 时，不能偷孩子 `4`、`5`，但可以考虑孙子。另一种方案是偷 `4` 和 `5`，它们是兄弟节点，不是直接相邻的父子节点，因此可以同时偷，金额为 `4 + 5 = 9`。答案为 `9`。

## 五、三个问题的状态变化

| 题目 | 房屋结构 | 状态的核心信息 | 处理方式 |
|---|---|---|---|
| 打家劫舍 I | 直线 | 前一个、前两个位置的最优金额 | 一维 DP，滚动两个变量 |
| 打家劫舍 II | 首尾相连的环 | 是否排除第一间或最后一间 | 拆成两个线性区间，各自做 I |
| 打家劫舍 III | 二叉树 | 当前节点偷 / 不偷两种结果 | 后序遍历，树形 DP |

## 六、常见错误

1. **把 II 当成普通直线处理。** 这样可能同时选择首尾两间。应拆成“去掉首间”和“去掉尾间”两个范围。
2. **III 每个节点只存一个最大值。** 父节点需要知道孩子是否被偷，因此至少要保留“偷”和“不偷”两种状态。
3. **III 先计算父节点再递归孩子。** 父节点的状态依赖孩子结果，应使用后序遍历。
4. **滚动变量更新顺序错误。** 先用旧的 `prevTwo`、`prevOne` 算出 `current`，再更新两个旧状态。
5. **对空树没有定义结果。** 空节点的两种 DP 状态都为 `0`，整棵树为空时答案为 `0`。

## 总结

三道题共享“当前元素选或不选”的决策。线性数组中，不偷当前房屋沿用前一状态，偷当前房屋则加上前两个位置的状态；环形结构通过排除一个端点拆成两种线性情况；树形结构则为每个节点保存偷与不偷两种结果，并用后序遍历自底向上计算。
