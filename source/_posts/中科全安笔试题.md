## 中科全安笔试题答案

1、clickhouse建表语句

````sql
-- 创建数据库
CREATE DATABASE IF NOT EXISTS netflow_db;

-- 创建NetFlow原始数据表（五元组 + 纠正后字段）
CREATE TABLE netflow_db.flow_records
(
    -- 原始五元组（从CSV读取）
    raw_src_ip String,
    raw_dst_ip String,
    raw_src_port UInt16,
    raw_dst_port UInt16,
    start_time DateTime64(3),
    
    -- 纠正后的五元组（程序处理后的标准化数据）
    src_ip String,
    dst_ip String,
    src_port UInt16,
    dst_port UInt16,
    
    -- 方向标记：0=内对内, 1=内对外, 2=外对内, 3=未知
    direction UInt8,
    
    -- 内外网标记（0=公网, 1=私网）
    src_is_private UInt8,
    dst_is_private UInt8,
    
    -- 会话ID（用于关联双向流）
    session_id String,
    
    -- 入库时间
    insert_time DateTime DEFAULT now()
)
ENGINE = MergeTree()
PARTITION BY toYYYYMMDD(start_time)
ORDER BY (start_time, src_ip, dst_ip, src_port, dst_port)
SETTINGS index_granularity = 8192;
````

4、Netflow为什么分不清源和目的？

Netflow是网络设备（路由器/交换机）采集的，它基于数据包的方向定义源和目的，这表明数据包的方向在业务方可能是相反的，例如，假设客户端--》服务端是正常的数据包方向，而服务端--》客户端则是想反的，但对于采集的数据包来说，源和目的是正确的。

5、如何区分Netflow的源和目的？

- 目的服务端提供的服务通常是知名端口即端口号<1024和知名服务的端口号，例如ssh22端口，Mysql3306端口，redis6379端口。
- 公网IP访问私网时，公网是客户端，私网IP通常是服务端
- 服务端端口通常不会改变，而客户端端口号来自不同区域即是不同的ip地址

7、如何区分扫描、暴力破解IP；

**扫描行为特征：**

```plain
1. 横向扫描：1个IP → N个不同IP的相同端口（如扫描整个网段的22端口）
2. 端口扫描：1个IP → 1个目标IP的N个不同端口
3. 综合扫描：1个IP → N个IP的N个端口
4. 高频特征：短时间内大量新建连接（源端口变化快）
```

**暴力破解特征：**

```plain
1. 目标明确：针对特定服务端口（22/3389/3306等）
2. 频率稳定：持续尝试，间隔规律
3. 单目标深度：对单个目标IP+端口有大量连接
4. 失败特征：连接时间短、数据量小（认证失败后断开）
```

- 二是在创建表时创建对应的物化视图(必须在创建表时同时创建，物化视图不会从历史数据中更新视图)，这样就能在插入数据后，直接从物化视图中查询

  阈值取5

  - **扫描Ip**

  ```sql
  -- 创建物化视图：扫描检测（按源IP聚合）
  CREATE MATERIALIZED VIEW netflow_db.mv_scan
  ENGINE = SummingMergeTree()
  PARTITION BY toYYYYMMDD(time_window)
  ORDER BY (src_ip, time_window)
  AS SELECT
      src_ip,
      toStartOfFiveMinute(start_time) as time_window,
      count() as flow_count,
      uniqExact(dst_ip) as unique_hosts,
      uniqExact(dst_port) as unique_ports,
      uniqExact((dst_ip, dst_port)) as unique_targets
  FROM netflow_db.flow_records
  GROUP BY src_ip, time_window;
  ```

  ```sql
  select src_ip from mv_scan where unique_targets >= 5 group by src_ip;
  ```

  - **暴力破解的ip**

  ```sql
  -- 创建物化视图：扫描检测（按源IP聚合）
  ```
