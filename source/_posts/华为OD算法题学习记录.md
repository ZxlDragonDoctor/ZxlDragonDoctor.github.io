# 算法题学习记录

覆盖本场对话中的 7 道题：题意要点、解法模板、自己代码里踩过的坑、以及通用注意事项。

---

## 一、电网负载均衡（连通块 / BFS / 并查集）

**题意**：N 个节点有负载，M 条无向边。同一连通块为一个供电区。  
不均衡度 =（最大负载 − 最小负载）× 节点数。输出所有供电区中的最大值；无有效供电区（节点数 &lt; 2）输出 `-1`。

**解法**：

- BFS/DFS：按未访问点枚举连通块，块内统计 max / min / size。
- 并查集：`union` 时在根上合并 `size / max / min`，最后扫根。

**踩过的坑**：

| 坑 | 现象 | 正确做法 |
|----|------|----------|
| 把无向图当有向图 | 只扫 `g[j][0]==t`，边写成 `[2,1]` 时从 1 找不到 2 | 邻接表两端都加边 |
| 无解输出错误 | 全是孤立点时打印 `Integer.MIN_VALUE` | 无有效区时输出 `-1` |
| 样例掩盖 bug | `[[0,1],[1,2],[3,4]]` 恰好是小→大，单向 BFS 也能过 | 必须造反向边反例 |

**注意**：

- 两条件写法：`(max-min)*size`，size &lt; 2 直接跳过。
- 并查集只要聚合信息时更干净；需要块内列表时用 BFS/DFS。
- 通用坑点：**先看有向还是无向边**。

## 二、末世资源分配（二分答案 + 贪心 / 回溯）

**题意**：把 `nums[n]` 切成恰好 k 段连续子数组，每段至少 1 个，最小化「段和最大值」。

**解法（正解）**：二分答案 + 贪心判定。

- 下界 `lo = max(nums)`，上界 `hi = sum(nums)`。
- `check(mid)`：贪心分段，段和一旦超过 `mid` 就断；段数 `≤ k` 可行则 `hi = mid`。
- 复杂度 `O(n log Σ)`。

**回溯写法（仅适合 n 很小）踩过的坑**：

| 坑 | 原写法 | 正确写法 |
|----|--------|----------|
| 递归传参错误 | `dfs(cur+1, startIndex, i+1)` | `dfs(cur+1, i, i+1)`，上一段结束下标是 `i` |
| 回溯不对称 | 叶子 `Misum.add` 后不 `remove` | add / remove 成对 |
| 最后一段为空 | `for i = start; i < n` 吃光剩余 | `i <= n - (k-cur) - 1`，给后面每段留 1 个 |
| 剪枝 off-by-one | `startIndex > n-(k-cur)` | `n - startIndex < k-cur+1` 时剪掉 |
| 算法选错 | `n≤1000` 还用全量回溯 | 二分 + 贪心，否则 TLE |

**注意**：

- `k=2` 样例可能碰巧对，`k≥3` 才暴露 preIndex 错误。
- 判定里段数 `cnt ≤ k` 而非 `== k`（还能再切，最大段和不会变差）。

## 三、LLM 推理批次最大化（最多不相交区间）

**题意**：区间 `[Li,Ri]`，选尽量多互不重叠的区间。  
**端点相接算重叠**（`[1,3]` 与 `[3,5]` 在 3 上冲突）。

**解法**：按**右端点升序**排序，能选则选。

```text
sort by Ri
end = 第一个的 Ri
for 后续区间:
    if Li > end:   # 严格大于，相接算重叠
        ans++
        end = Ri
```

**踩过的坑**：

| 坑 | 现象 | 正确做法 |
|----|------|----------|
| 按左端点排序 | `[[1,10],[2,3],[4,5]]` 得 1，期望 2 | 按右端点升序 |
| 相接当不重叠 | 用 `>=` 会同时选 `[1,3][3,5]` | 条件用 `Li > end` |
| 空数组 | 打印 1，且继续用 `arr[0]` 越界 | 输出 `0` 并 `return` |

**注意**：

- 口诀：**最多不相交 → 按结束时间排序；相接算重叠 → `>` 不是 `≥`**。
- 若坚持按左端点排序，必须在选不上时 `end = min(end, Ri)` 收紧，否则同样错。

## 四、二进制位翻转（大整数 / 进制）

**题意**：十进制大整数（最多 100 位）→ 二进制表示全部位反转（最低位变最高位）→ 再输出十进制。无前导零（除非 0）。

**解法**：

```java
BigInteger n = new BigInteger(s);
String rev = new StringBuilder(n.toString(2)).reverse().toString();
System.out.println(new BigInteger(rev, 2).toString());
```

**踩过的坑 / 易混**：

| 点 | 说明 |
|----|------|
| `toString(2)` 的 2 | 进制 radix，转成二进制串 |
| `new BigInteger(rev, 2)` 的 2 | 把字符串按二进制解析 |
| 省略 radix | 默认十进制，`"011"` 会变成十一 |
| 不要定宽补码翻转 | 题目说的是「二进制表示」的位序，不是固定位宽寄存器 |

**示例**：`6 → 110 → 011 → 3`；`4 → 100 → 001 → 1`；`1 → 1`。

## 五、小牛牛超市选品（滑动窗口）

**题意**：选一段连续商品，满足：

1. 总价 **严格大于** `limit`
2. 最贵单价 **≤** `limit`

求最短长度；不存在输出 `0`。

**解法**：双指针窗口。单价 `> limit` 是屏障（重置窗口）；全为正数时，和一旦 `> limit` 就左移收缩求最短。

**踩过的坑**：

| 坑 | 现象 | 正确做法 |
|----|------|----------|
| `max` 重算不清零 | 窗口弹出大值后残留，`[8,3,3,3]` 全被误杀 | 每次重算前 `max = MIN_VALUE` |
| 无解输出 | 打印 `Integer.MAX_VALUE` | 无解输出 `0` |
| 用 max 过滤而不是切断 | 大值商品留在窗口里靠条件过滤，状态脏 | 直接 `if (a[r] > limit)` 重置窗口 |

**注意**：两个不等号方向不同——**和是 `>`，最大单价是 `≤`**。

## 六、弹簧跑道（BFS / DP 最短路）

**题意**：从 0 出发到 `≥ n-1`。默认每次 +1；站在 `tiles[i]==1` 上时下一步可 +2；落点 `-1` 死。求最少步数，不能通关输出 `-1`。

**解法**：BFS/DP（只向右，无后效性）。

- 落点是 `-1` 不能落，但 **+2 可以跳过中间的陷阱**。
- 移动后 `≥ n-1` 立即通关。

**示例**：`0,1,-1,0,0` → `0→1→3→4`，3 步。

**注意**：

- 「可以 +2」是可选项，最短路里两种都试，不必纠结强制/可选。
- 终点本身是陷阱时，从 `n-2` 跳 2 格越过也算赢。
- `n=1` 已通关，输出 `0`。

## 七、菌子加工调度（状压 DP）

**题意**：串行加工，每个 5 小时；  
实际价值 = 初始价值 − 衰减速度 × 开始前等待时间；加工中不衰减。  
总耗时 ≤ `total`；价值衰到 0 或负则不加工。最大化总价值。  
`count ≤ 15`，`total ≤ 75`。

**解法**：`dp[mask]` = 加工集合 `mask` 的最大总价值。

- 新加工者排在第 `bitCount(mask)` 个，开始时间 = `5 × bitCount(mask)`。
- `gain = values[i] - decays[i] * start`，仅当 `gain > 0` 才转移。
- 答案为所有 `mask` 中 `dp` 的最大值（不必强行用满时间）。

**注意**：

- 等待时间是**开始加工前**的等待，不是完工时间。
- 固定加工时长时，**衰减快的先加工**（重排不等式）；状压 DP 会自动试出，不必手工排序。
- 复杂度 `O(2ⁿ·n)`，`n=15` 约 50 万，安全。
- `gain == 0` 也不要加工（题面：衰至零或负不再售卖）。

## 通用踩坑清单（跨题）

1. **图是无向还是有向**——连通块题第一件事。
2. **无解 / 空结果的输出约定**——常见 `-1` 或 `0`，不要打印 `Integer.MAX_VALUE` / `MIN_VALUE`。
3. **回溯必须对称清理**——路径上的 add / remove 成对出现。
4. **递归状态参数含义写清楚**——尤其是「上一段结束下标」这类，传错只在多层时暴露。
5. **分割类题目注意空段**——每段至少 1 个元素时，循环上界要给后面留料。
6. **贪心排序键**——最多不相交按**结束**时间；区间覆盖类各有各的键，先确认目标。
7. **闭区间相接是否算重叠**——题目会明确说；算重叠用 `>`，不算用 `≥`。
8. **严格不等 vs 非严格**——`sum > limit` 与 `max ≤ limit` 同时出现时，方向不要写反。
9. **滑动窗口重算聚合量（max/min）要先重置**。
10. **约束决定算法**——`n≤15` 想状压；`n≤20` 可回溯；`n≤1e5` 只能 `O(n)` / `O(n log n)`。
11. **大整数进制**——`toString(radix)` / `new BigInteger(s, radix)` 的第二个参数是进制。
12. **跳跃 / 瞬移类**——一般落点才算「踩」，可跳过中间危险格（以题面为准）。

## 题型速查

| 题目 | 模板 | 核心条件 |
|------|------|----------|
| 电网负载均衡 | BFS / 并查集求连通块 | `(max-min)*size` |
| 末世资源分配 | 二分答案 + 贪心判定 | 最小化最大段和 |
| 推理批次最大化 | 按结束时间排序贪心 | `Li > end` |
| 二进制位翻转 | BigInteger + reverse | radix = 2 |
| 超市选品 | 双指针最短窗口 | `sum > lim` 且 `max ≤ lim` |
| 弹簧跑道 | BFS/DP 最短路 | +1 / 弹簧后 +2，避 `-1` |
| 菌子加工 | 状压 DP | 开始时间 = 5×已做数量 |
