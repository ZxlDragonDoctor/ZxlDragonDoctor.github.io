# Java 优先队列与分治合并：从合并 K 个有序链表到有序数组

合并多个有序序列，是很适合学习优先队列和分治思想的一类题目。

这篇文章围绕三个问题展开：

1. 使用优先队列合并 K 个有序链表
2. 使用分治法合并 K 个有序链表
3. 使用分治法合并 K 个有序数组

三种方法都利用了“局部有序”的条件，但组织计算的方式不同。读完后，你应该能知道什么时候用优先队列，什么时候用分治，以及 Java 中如何定义队列元素的优先级。

---

## 一、先认识 Java 的 `PriorityQueue`

### 1. 什么是优先队列？

普通队列通常按照先进先出的顺序取元素。优先队列则会根据元素的优先级决定取出顺序。

Java 的 `PriorityQueue` 默认是**最小值优先**：队头是当前最小的元素。调用 `poll()` 会取出并移除队头；调用 `peek()` 只查看队头，不移除元素。Oracle 文档列出的复杂度是：插入和取出为 `O(log n)`，查看队头为 `O(1)`。[Oracle Java PriorityQueue 文档](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/PriorityQueue.html)

常用方法如下：

| 方法 | 作用 |
|---|---|
| `offer(value)` | 将元素加入队列 |
| `poll()` | 取出并移除队头；队列为空时返回 `null` |
| `peek()` | 查看队头但不移除；队列为空时返回 `null` |
| `isEmpty()` | 判断队列是否为空 |
| `size()` | 获取队列中的元素数量 |

例如：

```java
PriorityQueue<Integer> queue = new PriorityQueue<>();

queue.offer(5);
queue.offer(2);
queue.offer(8);

System.out.println(queue.peek()); // 2，不移除
System.out.println(queue.poll()); // 2，取出并移除
System.out.println(queue.poll()); // 5
```

注意：优先队列只保证队头是当前优先级最高的元素。遍历队列时，元素不一定按排序顺序出现；如果需要依次取出排序结果，应反复调用 `poll()`。

### 2. `PriorityQueue` 怎么知道元素的优先级？

如果队列中放的是 `Integer`，Java 知道如何比较它们。

如果放的是自定义对象，就要告诉队列如何比较。常见做法有两种：

- 让类实现 `Comparable<T>`，定义对象的自然顺序；
- 创建 `PriorityQueue` 时传入 `Comparator<T>`，由队列使用指定规则比较。

#### 使用 `Comparable`

```java
class Status implements Comparable<Status> {
    int val;

    Status(int val) {
        this.val = val;
    }

    @Override
    public int compareTo(Status other) {
        return Integer.compare(this.val, other.val);
    }
}
```

`compareTo` 的返回值表示：

- 小于 `0`：当前对象排在 `other` 前面；
- 等于 `0`：两者优先级相同；
- 大于 `0`：当前对象排在 `other` 后面。

这里使用 `Integer.compare`，比直接写 `this.val - other.val` 更稳妥，因为减法有整数溢出的可能。

#### 使用 `Comparator`

也可以不让类实现 `Comparable`，而是在创建队列时指定比较方式：

```java
PriorityQueue<Status> queue =
        new PriorityQueue<>((a, b) -> Integer.compare(a.val, b.val));
```

两种方式选一种即可。对于某个类有固定、自然的排序规则，可以实现 `Comparable`；如果排序规则由使用场景决定，传入 `Comparator` 更灵活。

## 二、问题一：用优先队列合并 K 个有序链表

### 1. 问题描述

给定 `k` 条升序链表，将它们合并为一条升序链表。

例如：

```text
链表 1：1 → 4 → 5
链表 2：1 → 3 → 4
链表 3：2 → 6

结果：1 → 1 → 2 → 3 → 4 → 4 → 5 → 6
```

### 2. 核心思路

每条链表都已经有序，所以每条链表当前尚未合并的头节点，就是这条链表中最小的候选值。

我们只需要反复做两件事：

1. 从所有候选节点中取出最小的一个，接到结果链表末尾；
2. 把这个节点所在链表的下一个节点放进候选集合。

用优先队列保存候选节点，就能快速找到当前最小值。

### 3. `Status` 为什么要保存 `val` 和 `ptr`？

队列需要根据节点值排序，但取出后还要知道对应的链表节点。因此我们创建一个辅助类，把比较用的值和节点指针放在一起：

```java
static class Status implements Comparable<Status> {
    int val;
    ListNode ptr;

    Status(int val, ListNode ptr) {
        this.val = val;
        this.ptr = ptr;
    }

    @Override
    public int compareTo(Status other) {
        return Integer.compare(this.val, other.val);
    }
}
```

其中：

- `val` 用来比较优先级；
- `ptr` 指向原链表节点，方便把节点接到结果链表上。

### 4. 完整代码

以下代码使用原链表节点拼接结果，不会为每个值额外创建新节点。`ListNode` 定义沿用题目提供的定义。

```java
import java.util.PriorityQueue;

class Solution {
    static class Status implements Comparable<Status> {
        int val;
        ListNode ptr;

        Status(int val, ListNode ptr) {
            this.val = val;
            this.ptr = ptr;
        }

        @Override
        public int compareTo(Status other) {
            return Integer.compare(this.val, other.val);
        }
    }

    public ListNode mergeKLists(ListNode[] lists) {
        if (lists == null || lists.length == 0) {
            return null;
        }

        PriorityQueue<Status> queue = new PriorityQueue<>();

        // 每条非空链表先放入头节点
        for (ListNode node : lists) {
            if (node != null) {
                queue.offer(new Status(node.val, node));
            }
        }

        ListNode dummy = new ListNode(0);
        ListNode tail = dummy;

        while (!queue.isEmpty()) {
            Status current = queue.poll();

            // 把最小节点接到结果链表
            tail.next = current.ptr;
            tail = tail.next;

            // 该节点所在链表还有后续节点，就加入队列
            if (current.ptr.next != null) {
                ListNode next = current.ptr.next;
                queue.offer(new Status(next.val, next));
            }
        }

        return dummy.next;
    }
}
```

`dummy` 是哑节点，作用是让我们可以统一地把节点接到结果链表尾部。真正的头节点是 `dummy.next`。

### 5. 用小例子走一遍

假设候选节点分别是 `1、1、2`：

| 操作 | 取出的节点 | 加入队列的新节点 | 结果链表 |
|---|---:|---:|---|
| 第 1 轮 | 1 | 4 | 1 |
| 第 2 轮 | 1 | 3 | 1 → 1 |
| 第 3 轮 | 2 | 6 | 1 → 1 → 2 |
| 第 4 轮 | 3 | 4 | 1 → 1 → 2 → 3 |

每轮只处理一个最小候选节点。队列中始终至多有每条链表的一个候选节点，因此队列最多保存 `k` 个元素。

### 6. 复杂度

设所有链表总共有 `N` 个节点，链表数量为 `k`：

- 时间复杂度：`O(N log k)`。每个节点入队、出队一次，每次操作至多花费 `O(log k)`。
- 额外空间复杂度：`O(k)`，用于优先队列。

## 三、问题二：用分治法合并 K 个有序链表

优先队列法每次从 `k` 个候选节点里挑出最小值。另一种方法是把链表两两合并，这就是分治法。

### 1. 核心思路

把 `k` 条链表分成左右两组：

1. 递归合并左边的链表；
2. 递归合并右边的链表；
3. 将左右两边合并后的结果再合并成一条链表。

这和归并排序的思路相同：先拆分，再逐层合并。

### 2. 合并两条有序链表

下面的 `mergeTwoLists` 每次比较两条链表的当前节点，把较小节点接到结果尾部：

```java
private ListNode mergeTwoLists(ListNode left, ListNode right) {
    ListNode dummy = new ListNode(0);
    ListNode tail = dummy;

    while (left != null && right != null) {
        if (left.val <= right.val) {
            tail.next = left;
            left = left.next;
        } else {
            tail.next = right;
            right = right.next;
        }
        tail = tail.next;
    }

    // 至少有一条链表已经处理完，接上另一条的剩余部分
    tail.next = (left != null) ? left : right;

    return dummy.next;
}
```

### 3. 完整代码

```java
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        if (lists == null || lists.length == 0) {
            return null;
        }

        return mergeRange(lists, 0, lists.length - 1);
    }

    private ListNode mergeRange(ListNode[] lists, int start, int end) {
        // 区间内只有一条链表，不需要再合并
        if (start == end) {
            return lists[start];
        }

        int mid = start + (end - start) / 2;

        ListNode left = mergeRange(lists, start, mid);
        ListNode right = mergeRange(lists, mid + 1, end);

        return mergeTwoLists(left, right);
    }

    private ListNode mergeTwoLists(ListNode left, ListNode right) {
        ListNode dummy = new ListNode(0);
        ListNode tail = dummy;

        while (left != null && right != null) {
            if (left.val <= right.val) {
                tail.next = left;
                left = left.next;
            } else {
                tail.next = right;
                right = right.next;
            }
            tail = tail.next;
        }

        tail.next = (left != null) ? left : right;
        return dummy.next;
    }
}
```

这里的 `mid` 写成 `start + (end - start) / 2`，可以避免直接计算 `start + end` 时潜在的整数溢出。

### 4. 为什么分治能做到 `O(N log k)`？

每一层会把链表两两合并。每层处理的节点总数约为 `N`，而链表数量每层大致减半，因此总共约有 `log k` 层：

```text
第 1 层：合并相邻链表
第 2 层：合并更长的链表
第 3 层：继续合并
...
直到只剩一条链表
```

因此：

- 时间复杂度：`O(N log k)`；
- 递归栈空间：`O(log k)`；
- 如果像上面的代码一样复用原节点，合并过程不需要为每个节点额外分配空间。

## 四、问题三：用分治法合并 K 个有序数组

链表可以两两合并，数组也一样。

给定多个升序数组：

```text
[1, 4, 5]
[1, 3, 4]
[2, 6]
```

要求合并成：

```text
[1, 1, 2, 3, 4, 4, 5, 6]
```

### 1. 思路

递归地把数组区间分成左右两半，分别合并，然后将两个有序数组再合并成一个有序数组。

合并两个数组时，使用两个指针分别指向左右数组当前元素，每次把较小的元素放入结果数组。

### 2. 完整代码

```java
class MergeKSortedArrays {
    public int[] mergeKArrays(int[][] arrays) {
        if (arrays == null || arrays.length == 0) {
            return new int[0];
        }

        return mergeRange(arrays, 0, arrays.length - 1);
    }

    private int[] mergeRange(int[][] arrays, int start, int end) {
        if (start == end) {
            return arrays[start];
        }

        int mid = start + (end - start) / 2;

        int[] left = mergeRange(arrays, start, mid);
        int[] right = mergeRange(arrays, mid + 1, end);

        return mergeTwoArrays(left, right);
    }

    private int[] mergeTwoArrays(int[] left, int[] right) {
        int[] result = new int[left.length + right.length];

        int i = 0;
        int j = 0;
        int write = 0;

        while (i < left.length && j < right.length) {
            if (left[i] <= right[j]) {
                result[write++] = left[i++];
            } else {
                result[write++] = right[j++];
            }
        }

        while (i < left.length) {
            result[write++] = left[i++];
        }

        while (j < right.length) {
            result[write++] = right[j++];
        }

        return result;
    }
}
```

这段实现假设每个子数组都非 `null`，并且已经按升序排列。空数组可以正常参与合并。

### 3. 复杂度

设所有数组总共有 `N` 个元素，数组数量为 `k`：

- 时间复杂度：`O(N log k)`；
- 合并时需要创建结果数组，额外空间复杂度为 `O(N)`。

与链表不同，数组合并需要把元素写入新数组；上面的链表版本则直接复用已有节点。

## 五、三种方法怎么选？

| 方法 | 使用的数据结构 | 时间复杂度 | 额外空间 | 适合的场景 |
|---|---|---:|---:|---|
| 优先队列合并 K 条链表 | `PriorityQueue` | `O(N log k)` | `O(k)` | 想逐个取出当前最小值 |
| 分治合并 K 条链表 | 递归 + 两链表合并 | `O(N log k)` | `O(log k)` 递归栈 | 已经会合并两条有序链表 |
| 分治合并 K 个数组 | 递归 + 双指针 | `O(N log k)` | `O(N)` | 数组需要生成新的合并结果 |

这几种方法的时间复杂度相同，但思路不同：

- **优先队列**维护“当前所有序列的最小候选值”；
- **分治法**把很多小问题两两合并；
- **数组合并**和链表合并共享分治思路，但数组通常需要创建新的结果空间。

## 六、容易写错的地方

### 1. 优先队列比较器写反

最小堆中，较小的值应该排在队头：

```java
return Integer.compare(this.val, other.val);
```

如果写成：

```java
return Integer.compare(other.val, this.val);
```

队列就会变成最大值优先。

### 2. 用减法实现比较

不建议写：

```java
return this.val - other.val;
```

当两个整数相差很大时，减法可能溢出。使用 `Integer.compare` 更安全。

### 3. 误以为遍历优先队列就是有序的

`PriorityQueue` 保证的是每次 `poll()` 取出当前最小元素，不保证迭代器按从小到大的顺序遍历。

### 4. 合并链表时没有处理剩余节点

两条链表长度不一定相同。循环比较到其中一条为空后，必须把另一条剩余部分接到结果链表尾部：

```java
tail.next = (left != null) ? left : right;
```

### 5. 忘记处理空输入

当没有链表或数组时，应返回空结果：

```java
if (lists == null || lists.length == 0) {
    return null;
}
```

数组版本通常返回空数组：

```java
if (arrays == null || arrays.length == 0) {
    return new int[0];
}
```

## 总结

`PriorityQueue` 适合维护一组候选值，并不断快速取出当前最小值。在合并 K 个有序链表时，每条链表只需要把当前头节点放入队列，取出后再加入它的后继节点。

分治法则把 K 条链表或 K 个数组拆成更小的组合，递归合并左右部分。理解了“两条有序链表如何合并”或“两条有序数组如何合并”，就可以逐层推广到 K 条或 K 个。

可以记住这两个模板：

```text
优先队列：
放入每个序列的当前候选值
重复取最小值，并放入它所在序列的下一个值

分治合并：
递归拆成左右两部分
分别合并左右结果
再把两个有序结果合并
```
