# python考点

不可变数据类型：数值（Number）,字符（string）,元组（Tuple）

可变数据类型：列表（List）,集合（Set）,字典（Directory）

**这里的 可变与不变指代的是值的变化**





**字符不可根据下标赋值，而元组也不可 修改其值，字符可以看成是一种特殊的元组**

**与 C 字符串不同的是，Python 字符串不能被改变。向一个索引位置赋值，比如 word[0] = 'm' 会导致错误。**



元组表示方式：（ ）；**元组（tuple）与列表类似，不同之处在于元组的元素不能修改**

列表表示方式：[ ]；**相当于C语言的数组，元素可以重复，元素能够修改**

集合：{ } 或set()函数 ==》**集合中的元素不能重复，且只能存放一种类型的元素**

字典：{ } 里面存放的是键值对（双列集合）**键(key)必须使用不可变类型,集合中的键值（key）唯一，value能够重复**



​	

注意事项：！！！！

**如果你想创建只有一个元素的元组，需要注意在元素后面添加一个逗号，以区分它是一个元组而不是一个普通的值，这是因为在没有逗号的情况下，Python会将括号解释为数学运算中的括号，而不是元组的表示。如果不添加逗号，如下所示，它将被解释为一个普通的值而不是元组 **

```py
tup1 = ()    # 空元组
tup2 = (20,) # 一个元素，需要在元素后添加逗号

```



**步长，前开后闭（从后往前数一样）**

rang(11) 生成0到10的整数

```py
#!/usr/bin/python3
#  python 列表
str = 'Runoob'  # 定义一个字符串变量

print(str)           # 打印整个字符串
print(str[0:-1])     # 打印字符串第一个到倒数第二个字符（不包含倒数第一个字符）
print(str[0])        # 打印字符串的第一个字符
print(str[2:5])      # 打印字符串第三到第五个字符（包含第五个字符）
print(str[2:])       # 打印字符串从第三个字符开始到末尾
print(str * 2)       # 打印字符串两次
print(str + "TEST")  # 打印字符串和"TEST"拼接在一起
```

```py
>>> a = [1, 2, 3, 4, 5, 6]
>>> a[0] = 9
>>> a[2:5] = [13, 14, 15]
>>> a
[9, 2, 13, 14, 15, 6]
>>> a[2:5] = []   # 将对应的元素值设置为 [] 
>>> a
[9, 2, 6]
```

在 Python 中，集合使用大括号 {} 表示，元素之间用逗号 , 分隔。

另外，也可以使用 set() 函数创建集合。

**注意：创建一个空集合必须用 set() 而不是 { }，因为 { } 是用来创建一个空字典。**

构造函数 dict() 可以直接从键值对序列中构建字典如下：

````py
>>> dict([('Runoob', 1), ('Google', 2), ('Taobao', 3)])
{'Runoob': 1, 'Google': 2, 'Taobao': 3}
>>> {x: x**2 for x in (2, 4, 6)} # python推导式
{2: 4, 4: 16, 6: 36}
>>> dict(Runoob=1, Google=2, Taobao=3)
{'Runoob': 1, 'Google': 2, 'Taobao': 3}
````
