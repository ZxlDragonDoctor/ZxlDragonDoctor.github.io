# 回文子串学习笔记：暴力枚举、动态规划与中心扩展

## 对应力扣题目

[647. 回文子串（Palindromic Substrings）](https://leetcode.com/problems/palindromic-substrings/)

题目要求统计字符串中所有回文**子串**的数量。子串必须连续；不同位置出现的相同字符串要分别计数。例如 `"aaa"` 中有 3 个 `"a"`、2 个 `"aa"` 和 1 个 `"aaa"`，答案是 `6`。

本文介绍三种常见方法：

1. 暴力枚举子串并逐个判断。
2. 动态规划，记录每个区间是否为回文。
3. 中心扩展，从每个可能的回文中心向两边扩展。

---

## 一、先区分子串和子序列

- **子串（substring）**：字符串中连续的一段字符。
- **子序列（subsequence）**：可以跳过一些字符，但保留剩余字符的相对顺序。

例如字符串 `"aba"` 中，`"aa"` 是子序列，但不是子串，因为两个 `a` 中间隔着 `b`。

这也是回溯代码容易出错的地方：如果循环里可以跳过字符并递归选择后面的字符，那么枚举到的通常是子序列，不一定是子串。

---

## 二、最直接的方法：枚举每个子串

一个子串可以由左右端点 `left` 和 `right` 唯一确定。枚举所有满足 `left <= right` 的区间，再逐个检查是否回文即可。

```java
class Solution {
    public int countSubstrings(String s) {
        int n = s.length();
        int count = 0;

        for (int left = 0; left < n; left++) {
            for (int right = left; right < n; right++) {
                if (isPalindrome(s, left, right)) {
                    count++;
                }
            }
        }

        return count;
    }

    private boolean isPalindrome(String s, int left, int right) {
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}
```

长度为 `n` 的字符串有 `O(n²)` 个子串；每次判断最多要比较 `O(n)` 个字符，所以：

- 时间复杂度：`O(n³)`；
- 额外空间复杂度：`O(1)`。

这个方法容易理解，可以作为建立思路的起点。

## 三、动态规划：记录区间是否为回文

### 1. 定义状态

定义 `dp[i][j]` 表示子串 `s[i..j]` 是否为回文。

当两端字符相同时，整个区间是否为回文取决于里面的区间：

```text
dp[i][j] = s[i] == s[j] 且（区间长度 <= 2 或 dp[i + 1][j - 1] 为 true）
```

长度为 1 或 2 时不需要检查更里面的区间：

- 长度为 1：单个字符一定是回文。
- 长度为 2：两端字符相同就是回文。

### 2. 为什么只遍历右上三角？

二维表中，行下标是 `i`，列下标是 `j`。有效子串必须满足 `i <= j`；当 `i > j` 时，起点在终点右边，不代表有效区间。

因此只需要填写主对角线及其右侧的格子，也就是右上三角。下面把每个格子直接标成 `dp[i][j]`：

| 起点 `i` / 终点 `j` | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 0 | `dp[0][0]` | `dp[0][1]` | `dp[0][2]` | `dp[0][3]` |
| 1 | 无效 | `dp[1][1]` | `dp[1][2]` | `dp[1][3]` |
| 2 | 无效 | 无效 | `dp[2][2]` | `dp[2][3]` |
| 3 | 无效 | 无效 | 无效 | `dp[3][3]` |

主对角线 `i == j` 表示单个字符；主对角线右侧 `i < j` 表示更长的区间；左下部分 `i > j` 无效，因为起点已经在终点右边。

### 3. 为什么 `i` 要从右往左遍历？

当区间长度大于 2 时，计算 `dp[i][j]` 需要先知道内部区间 `dp[i + 1][j - 1]`。在表格中，它位于当前格子的**左下方一格**：行号加 1，列号减 1。

例如计算 `dp[0][4]` 时，需要先知道 `dp[1][3]`；计算 `dp[1][3]` 时，又需要先知道 `dp[2][2]`：

```text
先算 dp[2][2]  →  再算 dp[1][3]  →  最后算 dp[0][4]
```

因此，外层 `i` 必须从大到小，也就是从矩阵底部往顶部填。每一行内，`j` 从 `i` 增大到 `n - 1`，也就是从左往右填。这样需要的左下方状态已经算好。

内层循环从 `j = i` 开始，只处理合法区间。条件 `j - i <= 1` 会先处理长度为 1 或 2 的区间；Java 的 `||` 会短路，因此这些情况下不会访问无效的 `dp[i + 1][j - 1]`。

### 4. Java 实现

```java
class Solution {
    public int countSubstrings(String s) {
        if (s == null || s.length() == 0) {
            return 0;
        }

        int n = s.length();
        boolean[][] dp = new boolean[n][n];
        int count = 0;

        for (int i = n - 1; i >= 0; i--) {
            for (int j = i; j < n; j++) {
                if (s.charAt(i) == s.charAt(j)
                        && (j - i <= 1 || dp[i + 1][j - 1])) {
                    dp[i][j] = true;
                    count++;
                }
            }
        }

        return count;
    }
}
```

只有当 `dp[i][j]` 为 `true` 时才把答案加一。这里按区间位置计数，所以 `"aaa"` 中多个相同的 `"a"` 会分别计数，符合题意。

- 时间复杂度：`O(n²)`；
- 额外空间复杂度：`O(n²)`。

这是一种自底向上的迭代动态规划，不是递归动态规划。

## 四、中心扩展：不保存 DP 表

每个回文都可以从中心向两侧扩展。中心可能有两种：

- **奇数长度**：中心是某一个字符，例如 `"aba"` 的中心是 `b`。
- **偶数长度**：中心位于两个字符之间，例如 `"aa"` 的中心在两个 `a` 之间。

因此，对字符串中的每个位置，分别尝试 `(i, i)` 和 `(i, i + 1)` 两种中心；每匹配成功一次，就找到一个回文子串。

```java
class Solution {
    public int countSubstrings(String s) {
        int count = 0;

        for (int i = 0; i < s.length(); i++) {
            count += expand(s, i, i);       // 奇数长度回文
            count += expand(s, i, i + 1);   // 偶数长度回文
        }

        return count;
    }

    private int expand(String s, int left, int right) {
        int count = 0;

        while (left >= 0
                && right < s.length()
                && s.charAt(left) == s.charAt(right)) {
            count++;
            left--;
            right++;
        }

        return count;
    }
}
```

每个中心最多向两边扩展 `O(n)` 次，总共有 `O(n)` 个中心：

- 时间复杂度：`O(n²)`；
- 额外空间复杂度：`O(1)`。

对于这道题，中心扩展通常是空间更省、代码也比较直观的解法。

---

## 五、三种方法对比

| 方法 | 核心做法 | 时间复杂度 | 额外空间复杂度 |
|---|---|---:|---:|
| 暴力枚举 | 枚举区间，再逐字符判断回文 | `O(n³)` | `O(1)` |
| 动态规划 | 复用内部区间的回文结果 | `O(n²)` | `O(n²)` |
| 中心扩展 | 从每个奇数或偶数中心向外扩展 | `O(n²)` | `O(1)` |

还有更进阶的 **Manacher 算法**，可以在 `O(n)` 时间内处理回文半径，适合需要线性时间的场景；初学这道题时，通常先掌握动态规划和中心扩展。

## 六、回溯写法：源码、递归过程与问题

下面是最初的回溯代码。它在每次递归进入时检查当前拼出的字符序列是不是回文：

```java
class Solution {
    int ans = 0;

    public int countSubstrings(String s) {
        backTracing(s, 0, new StringBuilder());
        return ans;
    }

    public void backTracing(String s, int index, StringBuilder tar) {
        if (isVaild(tar)) {
            ans += 1;
        }

        for (int i = index; i < s.length(); i++) {
            tar.append(s.charAt(i));
            backTracing(s, i + 1, tar);
            tar.deleteCharAt(tar.length() - 1);
        }
    }

    public boolean isVaild(StringBuilder tar) {
        int left = 0;
        int right = tar.length() - 1;

        while (left < right) {
            if (tar.charAt(left) != tar.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}
```

### 1. 这段回溯在枚举什么？

每次循环都可以从 `index` 之后任意选一个字符 `s.charAt(i)`，然后递归到 `i + 1`。因此它枚举的是**保持原顺序的子序列**，而不是连续子串。

以 `s = "aba"` 为例，递归可以先选下标 `0` 的 `a`，再跳过下标 `1` 的 `b`，选下标 `2` 的 `a`，拼出 `"aa"`。`"aa"` 是回文子序列，但不是原字符串的连续子串。

### 2. 为什么会多计一个？

第一次调用 `backTracing` 时，`tar` 是空串。`isVaild` 对空串会返回 `true`：`left` 是 `0`，`right` 是 `-1`，循环不会执行，最后直接返回 `true`。于是空串也被加进答案，但题目只统计非空子串。

此外，`ans` 是成员变量。如果同一个 `Solution` 对象多次调用 `countSubstrings`，旧答案会保留下来；每次调用前应重置计数。

### 3. 如果用递归枚举连续子串

要保证连续，可以固定一个起点 `start`，然后每次只把右端点 `right` 向右移动一位。这样不会跳过字符：

```java
class Solution {
    private int count;

    public int countSubstrings(String s) {
        if (s == null || s.length() == 0) {
            return 0;
        }

        count = 0;
        for (int start = 0; start < s.length(); start++) {
            extendRight(s, start, start);
        }
        return count;
    }

    private void extendRight(String s, int start, int right) {
        if (right == s.length()) {
            return;
        }

        if (isPalindrome(s, start, right)) {
            count++;
        }

        // 只扩展到紧邻的下一个字符，保证子串连续
        extendRight(s, start, right + 1);
    }

    private boolean isPalindrome(String s, int left, int right) {
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}
```

这版递归能正确枚举连续子串，但每个区间都要重新检查回文，时间复杂度为 `O(n³)`，递归栈空间为 `O(n)`。实际解题通常优先使用前面的动态规划或中心扩展。

---

## 总结

解决回文子串问题时，先确认计数单位是“位置区间”，而不是“不同的字符串内容”，再确保所选字符连续。

- 暴力枚举适合理解题意；
- 动态规划通过 `dp[i + 1][j - 1]` 复用子问题，遍历右上三角；
- 中心扩展从每个可能的中心寻找回文，时间 `O(n²)`、空间 `O(1)`。
