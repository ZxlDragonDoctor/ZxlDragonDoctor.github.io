# VIM命令



在 Vim 中，替换指定内容的全部匹配可以通过 `:s` 命令完成。以下是具体用法和示例：

------

### 1. 替换整个文件中的内容

**命令：**

```vim
:%s/旧内容/新内容/g
```

- `%`：表示作用范围是整个文件。
- `s`：表示替换。
- `旧内容`：需要被替换的内容。
- `新内容`：替换后的内容。
- `g`：表示全局替换（如果不加 `g`，每行只会替换第一个匹配）。

**示例：** 将整个文件中所有的 `foo` 替换为 `bar`：

```vim
:%s/foo/bar/g
```

------

### 2. 替换某一行的内容

**命令：**

```vim
:s/旧内容/新内容/g
```

- 作用范围是当前行。

**示例：** 将当前行的 `apple` 替换为 `orange`：

```vim
:s/apple/orange/g
```

------

### 3. 替换特定范围内的内容

**命令：**

```vim
:起始行号,结束行号s/旧内容/新内容/g
```

- 替换范围为指定的行号之间。

**示例：** 将第 10 到第 20 行中的 `cat` 替换为 `dog`：

```vim
:10,20s/cat/dog/g
```

------

### 4. 交互式确认替换

如果你希望在每次替换时确认，可以加上 `c` 参数：

```vim
:%s/旧内容/新内容/gc
```

**操作：**

- Vim 会逐一跳转到匹配位置，并询问是否替换。
- 输入：
  - `y`：替换当前匹配。
  - `n`：跳过当前匹配。
  - `a`：替换所有匹配。
  - `q`：退出替换操作。
  - `l`：仅替换当前匹配并退出。

------

### 5. 忽略大小写替换

如果需要忽略大小写，可以加 `\c`：

```vim
:%s/旧内容/新内容/g\c
```

**示例：** 将所有大小写形式的 `Hello` 替换为 `hi`：

```vim
:%s/Hello/hi/g\c
```

------

### 6. 替换包含特殊字符的内容

如果要替换的内容包含 `/` 或其他特殊字符，可以用 `\` 转义。

**示例：** 将 `/path/to/old` 替换为 `/path/to/new`：

```vim
:%s/\/path\/to\/old/\/path\/to\/new/g
```

或者，使用 `#` 代替 `/`：

```vim
:%s#/path/to/old#/path/to/new#g
```

------

### 总结

1. 整个文件替换：

   ```vim
   :%s/旧内容/新内容/g
   ```

2. 范围替换：

   ```vim
   :起始行号,结束行号s/旧内容/新内容/g
   ```

3. 交互确认替换：

   ```vim
   :%s/旧内容/新内容/gc
   ```
