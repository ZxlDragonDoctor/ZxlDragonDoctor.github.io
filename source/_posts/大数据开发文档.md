##### 2.创建表

为了实现这三个业务需求，我们需要创建三个不同的事实表来存储最热门的景点、评分最高的景点和票价最优惠的景点的信息。以下是创建这些表的 SQL 语句，以及如何根据 `destination_dim` 表插入数据到这些表中的步骤。

### **1. 创建最热门景点表（`top_sales_fact`）**

```sql
CREATE TABLE top_sales_fact (
    destination_id STRING,       -- 景点ID
    destination_name STRING,     -- 景点名称
    sales INT,                   -- 景点销量
    province STRING              -- 省市自治区
)
ROW FORMAT DELIMITED 
FIELDS TERMINATED BY ','  -- CSV文件是以逗号分隔
LINES TERMINATED BY '\n'  -- 每行数据以换行符分隔
STORED AS TEXTFILE;       -- 存储为文本文件格式
```

### **2. 创建评分最高景点表（`top_rating_fact`）**


### **插入数据到这些表中**

#### **插入最热门景点数据（销量最高的十个景点）**

```sql
INSERT INTO top_sales_fact (destination_id, destination_name, sales, province)
SELECT destination_id, destination_name, sales, province
FROM (
    SELECT destination_id, destination_name, sales, province
    FROM destination_dim
    ORDER BY sales DESC
    LIMIT 10
) temp;
```

#### **插入评分最高景点数据（评分前十的景点）**

```sql
INSERT INTO top_rating_fact (destination_id, destination_name, rating, province)
SELECT destination_id, destination_name, rating, province
FROM (
    SELECT destination_id, destination_name, rating, province
    FROM destination_dim
    ORDER BY rating DESC
    LIMIT 10
) temp;
```

#### **插入票价最优惠景点数据（评分大于0.78票价最低的十个景点）**

```sql
INSERT INTO best_price_fact (destination_id, destination_name, rating, price, province)
SELECT destination_id, destination_name, rating, price, province
FROM (
    SELECT destination_id, destination_name, rating, price, province
    FROM destination_dim
    WHERE rating > 0.78
    ORDER BY price ASC
    LIMIT 10
) temp;
```
**注意**

报错：FAILED: SemanticException [Error 10004]: Line 4:9 Invalid table alias or column reference 'sales': (possible column names are: _col0, _col1, _col2, _col3)

因为 Hive 在 `SELECT` 子句中指定的列名在 `ORDER BY` 子句中可能无法直接引用。具体来说，Hive 会生成临时的列名（如 `_col0`, `_col1` 等），因此 `ORDER BY` 和 `LIMIT` 子句可能无法解析直接的列名。

解决方法  1.使用子查询 2.建立临时表





###获取表列名（hive采用的直接数据库模式,mysql）

Hive 的元数据通常存储在 Metastore 数据库中（例如 MySQL）。要查看 Hive 表的元数据（如表的列名、数据类型等），可以通过 MySQL 访问 Metastore 数据库。以下是具体步骤：

------

### **1. 连接到 Metastore 数据库**

1. **找到 Metastore 数据库的连接信息**：

   - 检查 Hive 的配置文件 

     ```
     hive-site.xml
     ```

     ，其中会有 Metastore 的连接信息，例如：

     ```xml
     <property>
         <name>javax.jdo.option.ConnectionURL</name>
         <value>jdbc:mysql://hostname:port/metastore_db</value>
     </property>
     <property>
         <name>javax.jdo.option.ConnectionUserName</name>
         <value>your_username</value>
     </property>
     <property>
         <name>javax.jdo.option.ConnectionPassword</name>
         <value>your_password</value>
     </property>
     ```

2. **登录 MySQL 数据库**： 使用 MySQL 客户端或工具（如 `mysql` 命令行、phpMyAdmin、DBeaver 等）连接到 Metastore 数据库：

   ```bash
   mysql -u your_username -p -h hostname -P port
   ```

   输入密码后进入数据库。

------

### **2. 查询表的元数据**

Hive 的表结构信息存储在多个表中，以下是关键表及其作用：

- **`TBLS`**：存储 Hive 表的基本信息。
- **`COLUMNS_V2`**：存储表的列名和数据类型。
- **`SDS`**：存储表的存储描述符 ID。
- **`DBS`**：存储数据库信息。

#### **查询表的列名和数据类型**

假设你要查询 `your_table_name` 的列名和数据类型：

1. 找到表的存储描述符 ID (`SD_ID`)：

   ```sql
   USE metastore_db;
   
   SELECT SD_ID
   FROM TBLS
   WHERE TBL_NAME = 'your_table_name';
   ```

2. 使用 `SD_ID` 获取列信息：

   ```sql
   SELECT COLUMN_NAME, TYPE_NAME
   FROM COLUMNS_V2
   WHERE CD_ID = (SELECT SD_ID FROM TBLS WHERE TBL_NAME = 'your_table_name');
   ```

------

### **3. 查询表的所有元数据**

如果需要完整的表元数据，可以结合 `TBLS`、`COLUMNS_V2`、`SDS` 和 `DBS` 进行查询：

#### 获取表所在的数据库和其他信息：

```sql
SELECT dbs.NAME AS database_name, tbls.TBL_NAME AS table_name, tbls.TBL_TYPE AS table_type
FROM TBLS tbls
JOIN DBS dbs ON tbls.DB_ID = dbs.DB_ID
WHERE tbls.TBL_NAME = 'your_table_name';
```

#### 获取表的列信息：

```sql
SELECT c.COLUMN_NAME, c.TYPE_NAME, c.COMMENT
FROM TBLS t
JOIN SDS s ON t.SD_ID = s.SD_ID
JOIN COLUMNS_V2 c ON s.CD_ID = c.CD_ID
WHERE t.TBL_NAME = 'your_table_name';
```

------

### **4. 导出结果**

可以将查询结果导出到文件：

1. 在 MySQL 命令行中：

   ```bash
   mysql -u your_username -p -h hostname -P port -e "SELECT COLUMN_NAME, TYPE_NAME FROM COLUMNS_V2 WHERE CD_ID = (SELECT SD_ID FROM TBLS WHERE TBL_NAME = 'your_table_name');" > output.csv
   ```

2. 或在 MySQL 客户端工具中，选择“导出”选项，保存为 CSV、Excel 等格式。

------

### **注意事项**

- **权限要求**：确保你的 MySQL 用户具有查询 Metastore 数据库的权限。
- **表名区分大小写**：Hive 默认表名不区分大小写，但查询时建议保持一致。
- **风险提示**：避免对 Metastore 数据库执行任何写操作，以免破坏元数据。

通过以上步骤，你可以轻松查询和导出 Hive 表的元数据。
