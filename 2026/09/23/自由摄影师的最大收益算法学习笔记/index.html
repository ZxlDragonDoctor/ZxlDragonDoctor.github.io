自由摄影师的最大收益 — 学习记录

来源：华为 OD 9/23 真题
标签：排序 + 动态规划 + 0-1 背包
语言：Java

1. 题目描述

小华是自由职业摄影师，接到 N 个拍摄订单。每个订单 i 包含：

属性 含义
times[i] 完成订单需要连续工作的天数
deadlines[i] 必须完成订单的截止日期
profits[i] 完成订单的收益

约束：

  • 从第 1 天开始工作
  • 一旦开始某个订单，必须连续完成，不能暂停或切换
  • 每天只能处理一个订单
  • 所有被选订单的完成时间 ≤ 各自截止日期
  • 可以放弃任意订单

目标：在满足所有约束下，求最大总收益。

输入 / 输出

  • 第一行：times，英文逗号分隔
  • 第二行：deadlines，英文逗号分隔
  • 第三行：profits，英文逗号分隔
  • 输出：一个整数，最大总收益

约束：1 ≤ N ≤ 500，数组元素均为正整数。

示例

解释：放弃 100 收益、要连做 3 天的大单，改做三个 1 天小单（40×3=120）。

2. 问题建模

本质是 带截止日期的加权任务调度：

每天只有一个单位的「时间资源」，每个订单占用 times[i] 个连续单位，价值是 profits[i]。

3. 关键性质：按截止日期升序（EDD）

定理：一定存在一个最优方案，其中被选订单按截止日期从小到大排列。

交换论证：

若相邻订单 i、j 满足 deadline[i] > deadline[j]，却先做 i 再做 j，交换为先 j 后 i：

  • j 更早完成 → 对更紧的截止日更有利
  • 原方案中两者都能完成，交换后完成时间只可能更早或不变（EDD 经典结论）

反复交换，总能得到一个截止日升序的可行最优解。

推论：排序后，顺序固定，只需决定「选或不选」→ 背包问题。

输入：

排序后：

订单 time deadline profit
A 1 2 40

capacity = min(6, 3) = 3

答案 120：第 1 天 A，第 2 天 C，第 3 天 D。

7. 为什么倒序（0-1 语义）

正序会重复使用同一订单

设 time = 3, profit = 10，正序 day = 3, 4, 5... 时：

变成完全背包。

倒序读到旧值

背包类型 枚举方向
0-1 背包（每件至多一次） 倒序
完全背包（可重复） 正序

8. 实现易错点

8.1 收益下标写错（致命）

  • n < 3：数组越界
  • n ≥ 3：答案必错

8.2 不排序

若不按 deadline 排序，「完成日是否超期」失去后效性，DP 会错。

8.3 正序枚举

变成完全背包，同一订单被多次计入。

8.4 dp 初始化

初始化 适用场景
全 0 收益全为正整数时可用（本题）
-1 表示不可达 更稳妥；有 0 / 负收益时必须

8.5 可行性条件

8.6 收益用 long

多单加总可能超出 int。

9. 复杂度
时间 O(N log N + N × capacity)，capacity = min(Σtimes, maxDeadline)
空间 O(capacity)

N ≤ 500，Σtimes 在几十万量级内可过。

10. 可复用模板

三个记忆点：

  1. 先按 deadline 排序（EDD）
  2. 倒序枚举 day（0-1，不重复用）
  3. 上界用 deadline（完成日 ≤ 截止日）

11. 与 0-1 背包对照

概念 经典 0-1 背包 本题
物品 重量 w、价值 v 工期 time、收益 profit
容量 固定 C 受 deadline 限制，上界 day ≤ deadline
约束 总重 ≤ C 总工期 = 完成日 ≤ 截止日
转移 dp[j] = max(dp[j], dp[j-w]+v) dp[day] = max(dp[day], dp[day-time]+profit)
枚举 倒序 倒序

12. 自查清单

  • 按 deadline 升序排序
  • 0-1 倒序枚举
  • 转移满足完成日 ≤ 截止日
  • 收益下标用 i，不是写死的 2
  • dp 初始化语义正确（0 或 -1）
  • 收益用 long
  • 用示例手算验证答案 120

13. 一句话总结

按截止日期排序后，问题退化为「带体积（工期）的 0-1 背包」，体积还多一个上界约束（完成日 ≤ 截止日）；把约束写进循环上界，倒序转移取 max(dp) 即可。
